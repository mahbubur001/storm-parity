# Run, Composer and terminal

- The **Run widget** in the status bar shows the selected run configuration (launch.json, tasks, npm and composer scripts) with Run, Debug and Stop. **Ctrl+Opt+R** runs any configuration, **Ctrl+Opt+D** debugs one.
- The **Composer** view (right Secondary Side Bar, Cmd+Opt+B) lists scripts and packages with installed versions, checks for updates and searches Packagist for *Require*.
- **Opt+F12** toggles the terminal. *Toggle Terminal Tabs Below* runs terminals as real tabs under the code, like PhpStorm.
