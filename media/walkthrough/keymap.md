# Keymap

Storm Parity mirrors PhpStorm macOS shortcuts, which override some VS Code defaults (F3, Cmd+O, Cmd+Shift+E, Cmd+Shift+U, Cmd+Shift+N, ...).

Turn off `stormParity.keymap.enabled` to keep every command but drop all the shortcuts. Each feature can also be disabled on its own under *Settings > Storm Parity*.
