# Keymap

Storm Parity mirrors PhpStorm macOS shortcuts, which override some VS Code defaults (Cmd+O, Ctrl+R, Cmd+Shift+E, Cmd+Shift+U, Cmd+Shift+N, Opt+F1, Opt+F12, ...).

Turn off `stormParity.keymap.enabled` to keep every command but drop all the shortcuts. Each feature can also be disabled on its own under *Settings > Storm Parity*, which drops its shortcuts too.
