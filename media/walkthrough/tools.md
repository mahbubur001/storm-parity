# Tools

- **Cmd+Shift+N** creates a scratch file. Scratches are global (shared by every project) and listed in a **Scratches** folder at the end of the **External Libraries** view in the Explorer.
- **External Libraries** adds folders outside the project (WordPress core, SDKs, stubs) for Intelephense to index.
- **Changelists** appear in the Source Control view; commit one list at a time.
- **Local History** (Put Label, Show History) keeps a snapshot on every save.
