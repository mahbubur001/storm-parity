# Edit faster

- **Cmd+Shift+V** pastes from clipboard history.
- **Cmd+Opt+T** surrounds the selection with if/try/foreach/tag templates.
- **Cmd+Shift+U** toggles case, **Ctrl+Opt+U** cycles camel/snake/kebab/Pascal.
- **PHP postfix completion**: type `$items.foreach`, `$user.if`, `$x.return`, `User.new` and pick the suggestion.
- *Compare with Clipboard* is in the editor context menu.
