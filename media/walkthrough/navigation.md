# Navigate

- **F3** toggles a bookmark, **Opt+F3** assigns a mnemonic (0-9, A-Z), **Ctrl+<digit>** jumps, **Cmd+F3** lists all.
- **Cmd+Shift+E** shows recent locations; press it again for *changed only*.
- **Cmd+Shift+A** searches files, symbols, actions and settings.
- **Cmd+Opt+Shift+C** copies a reference (PHP FQN, symbol path or `file:line`).
