# Open projects the PhpStorm way

- **Cmd+O** opens a folder and asks: *This Window*, *New Window* or *Attach*.
- **Ctrl+R** lists recent projects with the same prompt. For saved projects and tags, use the Project Manager extension.
- *Set Project Color* tints the window title bar so project windows are easy to tell apart.

Set `stormParity.openFolder.defaultAction` to skip the prompt.
